### dify+ragflow的使用

​	首先我们需要在docker中启动这两个工具，但是由于默认启动的端口都是一样的，所以我们需要修改配置文件，防止启动端口冲突。

**修改ragflow运行端口**

```yaml
ports:
  -${SVR_HTTP_PORT}:9380
  -80:80										// 前面改成别的
  -443:443									// 前面改成别的
  -5678:5678								// 前面改成别的
  -5679:5679								// 前面改成别的
  -9382:938									// 前面改成别的
```

**开启ragflow的MCP功能**

```yaml
command:
  - --enable-mcpserver
  - --mcp-host=0.0.0.8
  - --mcp-port=9382
  - --mcp-base-url=http://127.0.0.1:9380
  - --mcp-script-path=/ragflow/mcp/server/server.py
  - --mcp-mode=self-host
  - --mcp-host-api-key=ragflow-xxxxxxx
```

**启动ragflow后注册API**

​	在ragflow中获取其API的key值，复制该key值用于dify插件中的MCP SSE插件。同时，在ragflow配置文件中将--mcp-host-api-key的值赋值为该key值

**dify MCP SSE配置**

​	我们将ragflow中获取到的key值和ragflow地址设置进MCP SSE插件，保存即可。
